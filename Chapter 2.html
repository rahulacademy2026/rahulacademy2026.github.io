Exercise Set 2.1

Q1. Degrees

The degree is the highest power of the variable.
(i) 2x² − 5x + 3: degree 2
(ii) y³ + 2y − 1: degree 3
(iii) −9: degree 0
(iv) 4z − 3: degree 1

Q2. Examples of degrees 1, 2 and 3

Degree 1: 2x + 1
Degree 2: x² + 3x + 2
Degree 3: x³ − 2x + 4

Q3. Coefficients

In x⁴ − 3x³ + 6x² − 2x + 7, the coefficient of x² is 6 and the coefficient of x³ is −3.

Q4. Coefficient of z

There is no z term in 4z³ + 5z² − 11, so the coefficient of z is 0.

Q5. Constant term

The constant term of 9x³ + 5x² − 8x − 10 is −10.

Exercise Set 2.2

Q1. Evaluate 5x − 3

(i) x = 0: 5(0) − 3 = −3
(ii) x = −1: 5(−1) − 3 = −8
(iii) x = 2: 5(2) − 3 = 7

Q2. Evaluate 7s² − 4s + 6

(i) s = 0: 6
(ii) s = −3: 7(9) + 12 + 6 = 81
(iii) s = 4: 7(16) − 16 + 6 = 102

Q3. Salil and his mother's ages

Let Salil’s present age be x. His mother’s age is 3x.
(x + 5) + (3x + 5) = 70 ⇒ 4x + 10 = 70 ⇒ x = 15.
Salil = 15 years; mother = 45 years.

Q4. Two integers in ratio 2:5

Let the integers be 2k and 5k. Then 5k − 2k = 63 ⇒ 3k = 63 ⇒ k = 21.
The integers are 42 and 105.

Q5. Two-rupee and five-rupee coins

Let the number of ₹5 coins be x. Then ₹2 coins = 3x.
Total value: 5x + 2(3x) = 88 ⇒ 11x = 88 ⇒ x = 8.
₹5 coins = 8; ₹2 coins = 24.

Q6. Fence cut into two pieces

Let the shorter piece be x feet; the longer is 4x feet.
x + 4x = 300 ⇒ 5x = 300 ⇒ x = 60.
Shorter = 60 ft; longer = 240 ft.

Q7. Rectangle perimeter 24 cm

Let width = w cm; length = 2w + 3 cm.
2(l + w) = 24 ⇒ l + w = 12.
(2w + 3) + w = 12 ⇒ 3w = 9 ⇒ w = 3, so l = 9.
Width = 3 cm; length = 9 cm.

Exercise Set 2.3

Q1. Savings plus monthly pocket money

Starting amount = ₹500 and monthly addition = ₹150.
At the end of month n: A(n) = 500 + 150n.
Month 2: ₹800; month 3: ₹950; month 4: ₹1,100.

Q2. Rally members

Start with 120 members; 9 leave each hour.
After 1, 2, 3 hours: 111, 102, 93.
After n hours: M(n) = 120 − 9n (while the model remains non-negative).

Q3. Rectangle area

Area = length × breadth = 13b.
For breadths 12, 10, 8 cm, areas are 156, 130, 104 cm².
Across these cases, the area decreases by 26 cm² each time. If n = 1, 2, 3, … labels the listed cases, A(n) = 182 − 26n.

Q4. Rectangular box volume

Volume = 7 × 11 × h = 77h.
For heights 5, 9, 13 cm, volumes are 385, 693, 1001 cm³.
For stage n = 1, 2, 3, …, height h = 4n + 1, so V(n) = 77(4n + 1) = 308n + 77.

Q5. Pages left in a book

Pages remaining after d days: P(d) = 500 − 20d.
After 15 days: 500 − 20(15) = 500 − 300 = 200 pages.

Exercise Set 2.4

Q1. Plant growth

Height after t months: h(t) = 1.75 + 0.5t feet.
(i) After 7 months: 1.75 + 3.5 = 5.25 ft.
(ii) Table (t months → h feet):
0 → 1.75, 1 → 2.25, 2 → 2.75, 3 → 3.25, 4 → 3.75, 5 → 4.25, 6 → 4.75, 7 → 5.25, 8 → 5.75, 9 → 6.25, 10 → 6.75
(iii) The height increases by a constant 0.5 ft each month, so this is linear growth.

Q2. Phone depreciation

Value after t years: v(t) = 10000 − 800t rupees.
(i) After 3 years: 10000 − 2400 = ₹7,600.
(ii) Table (t years → value):
0 → ₹10,000, 1 → ₹9,200, 2 → ₹8,400, 3 → ₹7,600, 4 → ₹6,800, 5 → ₹6,000, 6 → ₹5,200, 7 → ₹4,400, 8 → ₹3,600
(iii) The value falls by ₹800 each year, so this is linear decay.

Q3. Village population

Population after t years: P(t) = 750 + 50t.
(i) After 6 years: 750 + 300 = 1,050 people.
(ii) Table (t years → population):
0 → 750, 1 → 800, 2 → 850, 3 → 900, 4 → 950, 5 → 1000, 6 → 1050, 7 → 1100, 8 → 1150, 9 → 1200, 10 → 1250
(iii) Population rises by 50 each year, so this is linear growth.

Q4. Prepaid balance

(i) Balance after x days: b(x) = 600 − 15x rupees. It decreases by a fixed ₹15 daily, so it is linear decay.
(ii) 600 − 15x = 0 ⇒ x = 40 days.
(iii) Table (days → balance):
1 → ₹585, 2 → ₹570, 3 → ₹555, 4 → ₹540, 5 → ₹525, 6 → ₹510, 7 → ₹495, 8 → ₹480, 9 → ₹465, 10 → ₹450

Exercise Set 2.5

Q1. Learning platform bill

Given: 10a + b = 400 and 14a + b = 500.
Subtract: 4a = 100 ⇒ a = 25.
b = 400 − 250 = 150.
Relationship: y = 25x + 150.

Q2. Gym bill

Given: 10a + b = 800 and 15a + b = 1100.
Subtract: 5a = 300 ⇒ a = 60.
b = 800 − 600 = 200.
Relationship: y = 60x + 200.

Q3. Celsius and Fahrenheit

Let C = aF + b. At F = 32, C = 0, so 0 = 32a + b. At F = 212, C = 100, so 100 = 212a + b.
Subtracting gives 100 = 180a ⇒ a = 5/9. Then b = −160/9.
C = (5/9)F − 160/9 = (5/9)(F − 32).

Exercise Set 2.6

Q1(i). Graphs y = 4x, y = 2x, y = x

All three lines pass through (0, 0). Slopes are 4, 2 and 1 respectively. Plot points such as:
y = 4x: (−1,−4), (0,0), (1,4).
y = 2x: (−1,−2), (0,0), (1,2).
y = x: (−1,−1), (0,0), (1,1).
Changing a changes the slope/steepness.

Q1(ii). Graphs y = −6x, y = −3x, y = −x

All pass through (0,0); slopes are −6, −3 and −1.
Useful points: for x = 1, y = −6, −3, −1 respectively; include (0,0) and join each pair with a straight line.

Q1(iii). Graphs y = 5x and y = −5x

Both pass through (0,0). Slopes are 5 and −5.
Points for y = 5x: (−1,−5), (0,0), (1,5).
Points for y = −5x: (−1,5), (0,0), (1,−5).

Q1(iv). Graphs y = 3x − 1, y = 3x, y = 3x + 1

All have slope 3, so they are parallel. Their y-intercepts are −1, 0 and 1.
Points: y=3x−1 → (0,−1),(1,2); y=3x → (0,0),(1,3); y=3x+1 → (0,1),(1,4).

Q1(v). Graphs y = −2x − 3, y = −2x, y = 2x + 3

Slopes and y-intercepts: −2 and −3; −2 and 0; 2 and 3.
Points: first line (0,−3),(1,−5); second (0,0),(1,−2); third (0,3),(1,5). The first two lines are parallel because their slopes are equal.

End-of-Chapter Exercises

Q1. Degree 3 polynomial

One valid answer is x³ − 7x² + x + 1. It has degree 3 and the coefficient of x² is −7.

Q2(i). Evaluate 5x² − 3x + 7 at x = 1

5(1)² − 3(1) + 7 = 5 − 3 + 7 = 9.

Q2(ii). Evaluate 4t³ − t² + 6 at t = a

Substitute t = a: 4a³ − a² + 6.

Q3. Number equation

The question gives (5/2)x + 2/3 = −7/12.
(5/2)x = −7/12 − 2/3 = −7/12 − 8/12 = −15/12 = −5/4.
x = (−5/4)(2/5) = −1/2.

Q4. Two positive numbers

Let the smaller number be x and the larger be 5x. After adding 21, the larger becomes twice the smaller:
5x + 21 = 2(x + 21) ⇒ 3x = 21 ⇒ x = 7.
The numbers are 7 and 35.

Q5. Savings pattern

After n months, amount = A(n) = 800 + 250n.
(i) 6 months: 800 + 1500 = ₹2,300.
(ii) 2 years = 24 months: 800 + 6000 = ₹6,800.

Q6. Two-digit numbers

Let the digits be a and b. Interchanging and adding gives 11(a+b) = 143, so a+b = 13. Their difference is 3, so the digits are 5 and 8.
The numbers are 58 and 85.

Q7(i). y = −3x + 4

Slope = −3; y-intercept = 4; y-axis crossing = (0, 4). Plot (0,4) and (1,1), then join.

Q7(ii). 2y = 4x + 7

y = 2x + 7/2. Slope = 2; y-intercept = 7/2; crossing = (0, 3.5). Plot (0,3.5) and (1,5.5).

Q7(iii). 5y = 6x − 10

y = (6/5)x − 2. Slope = 6/5; y-intercept = −2; crossing = (0,−2). Plot (0,−2) and (5,4).

Q7(iv). 3y = 6x − 11

y = 2x − 11/3. Slope = 2; y-intercept = −11/3; crossing = (0,−11/3). Lines (ii) and (iv) are parallel because both have slope 2.

Q8. Kelvin and Fahrenheit

(i) For x = 313 K: y = (9/5)(313−273)+32 = 72+32 = 104°F.
(ii) For y = 158°F: 158 = (9/5)(x−273)+32 ⇒ 126 = (9/5)(x−273) ⇒ x−273 = 70 ⇒ x = 343 K.
